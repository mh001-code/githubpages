Meus Projetos

Aqui estão alguns dos projetos em que trabalhei e que refletem minhas habilidades e experiências em desenvolvimento de software.

Sistema de Gestão de Pedidos para Auto Peças:

Sistema web completo para gestão de uma loja de autopeças, oferecendo funcionalidades essenciais como cadastro e gerenciamento de clientes, controle de produtos e pedidos, além de um módulo financeiro para acompanhamento de receitas e despesas. A solução foi desenvolvida para otimizar os processos internos, melhorar o atendimento e facilitar a tomada de decisões.

Tecnologias Utilizadas: Java – Lógica de back-end e regras de negócio. PostgreSQL – Banco de dados relacional para armazenamento seguro e eficiente das informações. HTML5 – Estruturação semântica das páginas web. CSS3 – Estilização e responsividade do layout. JavaScript – Funcionalidades interativas no front-end

Landing Page de Restaurante Delivery:

Esta é uma landing page de um restaurante, projetada para destacar os principais pratos e permitir fácil contato com os clientes. A página inclui um cardápio interativo, avaliações de clientes e links rápidos para pedidos. Com um design responsivo e elementos de mídia social, oferece uma experiência agradável tanto em dispositivos móveis quanto desktops.

Tecnologias Utilizadas: HTML5 – Estruturação semântica da página. CSS3 – Estilização visual com responsividade. JavaScript – Interatividade. Google Fonts – Tipografia personalizada. Font Awesome – Ícones (caso tenha usado). Media Queries – Adaptação para dispositivos móveis
